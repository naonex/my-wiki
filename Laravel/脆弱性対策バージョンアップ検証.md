## 直近でPHPの脆弱性が話題になったので、バージョンアップを検証してみる。

### Laravelバージョンアップ

#### composer.jsonのLaravelバージョンを上げる。

`"laravel/framework": "^12.69.0"`

#### パッケージをアップデートする。
./vendor/bin/sail composer update -W`

ここまでで、Laravelのバージョンアップは完了。続いて本題のPHPのバージョンアップを行う。

---

### PHPバージョンアップ

#### sailのイメージを再ビルド（参照先のPHPが更新されてればこれで上手くいくはず。。）

`./vendor/bin/sail build --no-cache laravel.test`

#### コンテナ再作成

`./vendor/bin/sail up -d --force-recreate laravel.test`

これでPHPのバージョンアップも完了。念のため以下にバージョンや脆弱性確認のコマンド貼っておきます。

---

### バージョンや脆弱性確認のコマンド

```
# Laravel,PHPのバージョン確認
./vendor/bin/sail artisan --version
./vendor/bin/sail php -v

# Laravelの脆弱性確認
./vendor/bin/sail composer audit
```
